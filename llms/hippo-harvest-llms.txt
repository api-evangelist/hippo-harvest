# Hippo Harvest

> Hippo Harvest is a controlled-environment agriculture company in Pescadero, California that
> grows USDA-certified-organic packaged leafy greens in modular greenhouses operated by custom
> autonomous mobile robots and machine learning. It sells salad greens into grocery retail. It
> does not sell software and publishes no API.

## API status

Hippo Harvest publishes **no public API, developer portal, SDK, webhook surface, or
machine-readable contract**. This was verified on 2026-08-22 against every host the company
controls:

- `https://www.hippoharvest.com/openapi.json`, `/openapi.yaml`, `/swagger.json`,
  `/v1/openapi.json`, `/api-docs`, `/docs`, `/redoc`, `/graphql`, `/api`, `/mcp` — all 404.
- `https://www.hippoharvest.com/llms.txt` — 404.
- Every `/.well-known/` path (`security.txt`, `openid-configuration`,
  `oauth-authorization-server`, `api-catalog`, `ai-plugin.json`, `agent-card.json`,
  `agent.json`) — all 404. See `well-known/hippo-harvest-well-known.yml`.
- No `api.`, `app.`, `developer.`, `docs.`, `portal.` or `status.` subdomain resolves in DNS.
- No first-party client library exists on npm, PyPI, RubyGems or crates.io.
- The company's GitHub organization (`Hippo-Harvest`, 2 public repos) contains a fork of the
  upstream `RobotWebTools/rosbridge_suite` and a frontend-engineer interview case study —
  neither is a published contract.

The robotics, computer-vision and growing-control software is internal operating
infrastructure for growing lettuce, not a product sold to customers.
